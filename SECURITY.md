# Security policy

## Supported versions

Only the latest commit on `main` is supported. Fixes are made on `main` only.

## Reporting a vulnerability

Do not open a public issue for a vulnerability.

Use the "Report a vulnerability" button in the Security tab of the repository:
https://github.com/tryph0n/hybrid-tracker/security/advisories/new

Include the steps to reproduce the problem and the effect you see. You get an
answer within 7 days.
