# Decision log

A decision record keeps the reason for a choice of service, storage or
framework. A later reader can then tell when the reason no longer holds. The
maintainer guide says [when a record is required, in the section "Record a decision"](../maintainer.md).

To add a record, copy [the template](template.md) to
`NNNN-short-title.md`, with the next free number, and fill in the four parts.
Add the file to the list below. A record is not edited when the decision
changes: a new record replaces it, and the old one gets the status
`Superseded by NNNN`.
