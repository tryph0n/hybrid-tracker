# Sources

This page records each source that the project considered, with its verdict,
its licence, the page that states the licence and the date of the check. No
source enters the data without a licence recorded here.

The groups are the verdicts:

- Use now: the licence allows redistribution under CC BY 4.0 or CC BY-NC 4.0.
- Official feed: no adapter. The items go to the review queue of official
  feeds (#61 and #57), because governments publish attributions as press
  releases, not as incident tables.
- Ask first: no licence, or no bulk republication. The source waits for a
  written permission that allows redistribution under CC BY or CC BY-NC.
  Answers are in [permissions](permissions.md).
- Link only: the terms forbid derivatives or redistribution, so the source is
  linked and never copied.
- Set aside: checked and not used, with the reason.

Usable means "Use now", or "Ask first" with a yes in
[permissions](permissions.md).

## Set aside

- Hackmageddon and the CyberPeace Institute conflict tracker: no open licence,

- MITRE ATT&CK groups: fallback for the MISP lookup.
